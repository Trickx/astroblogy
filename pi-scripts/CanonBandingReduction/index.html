CanonBandingReduction is now SensorDestripe

The script published here as CanonBandingReduction has been renamed to SensorDestripe. It works the same way and is found under Script > Tricx > SensorDestripe.

If you added this repository in PixInsight

The next Check for Updates installs SensorDestripe and removes CanonBandingReduction. Your saved settings are taken over. Then switch the repository entry to the new address:

  1. Resources > Updates > Manage Repositories
  2. Remove https://tricx.de/pi-scripts/CanonBandingReduction/
  3. Add https://tricx.de/pi-scripts/SensorDestripe/

This address will be taken offline in a later release.
