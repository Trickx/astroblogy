CanonBandingReduction

PixInsight update repository for the CanonBandingReduction script.

Reduces the horizontal banding of some Canon DSLRs by equalizing the background brightness of each image row. An optional highlight protection excludes bright pixels from the row background, so stars and nebulae do not cause overcorrection. The result can be checked in a live preview, optionally with the current STF.

Based on the original script by Georg Viehoever (2009-2013), ported to the V8 engine by Peter Proulx.

This page is informational. For PixInsight, use the repository URL shown below.

Installation in PixInsight

  1. Resources > Updates > Manage Repositories
  2. Add repository: https://tricx.de/pi-scripts/CanonBandingReduction/
  3. Run Check for Updates
  4. Run via Script > Tricx > CanonBandingReduction
