Histogram

PixInsight update repository for the Histogram script.

Displays a non-destructive histogram and statistics view for the active image, with separate RGB curves, grayscale support, logarithmic axes, zoom and range controls, percentiles, and clipping statistics.

This page is informational. For PixInsight, use the repository URL shown below.

Repository URL for PixInsight

https://tricx.de/pi-scripts/Histogramm/

Installation in PixInsight

  1. Resources > Updates > Manage Repositories
  2. Add repository: https://tricx.de/pi-scripts/Histogramm/
  3. Run Check for Updates
  4. Run via Script > Trickx > Histogram
