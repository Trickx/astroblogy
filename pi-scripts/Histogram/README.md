# Histogram (discontinued)

The PJSR script Histogram and its PixInsight update repository
(https://tricx.de/pi-scripts/Histogram/) are offline. `index.html` remains as a
notice for users who still have the repository registered in PixInsight. The
successor is the native module HistogramViewer (`../HistogramViewer/`).

The script, its packages and `updates.xri` are in the git history before their
removal.
