Histogram

The PJSR script Histogram has been discontinued, and its PixInsight update repository is offline.

Its successor is HistogramViewer, the same tool as a native PixInsight module: faster, and it follows the active image.

If you added this repository in PixInsight

PixInsight reports an error for https://tricx.de/pi-scripts/Histogram/ when it checks for updates. Remove the entry:

  1. Resources > Updates > Manage Repositories
  2. Select https://tricx.de/pi-scripts/Histogram/ and remove it

The installed script keeps working. To remove it as well, delete the folder src/scripts/Tricx/Histogram/ in the PixInsight installation directory and run Script > Feature Scripts > Regenerate.
